# Lab 01：Python开发环境配置与GitHub入门

## 一、实训目的

通过本次实训完成 Python 程序开发环境配置，掌握 Python 程序的创建、运行和基本调试方法，能够编写简单的交互式 Python 程序，并初步了解 GitHub 在课程代码管理和实训项目管理中的基本使用方法，为后续课程学习和综合项目开发做好准备。

## 二、实训内容

本次实训主要包括以下内容：

1. 检查并配置 Python 开发环境；
2. 创建并运行第一个 Python 程序；
3. 掌握变量、输入和输出的基本使用；
4. 完成一个简单的交互式 Python 程序；
5. 熟悉课程 GitHub 仓库的基本结构；
6. 完成个人实训代码的基本管理。

## 三、任务1：检查 Python 开发环境

打开终端或命令提示符，执行：

```bash
python --version
```

如果系统中同时安装了多个 Python 版本，也可以尝试：

```bash
python3 --version
```

正常情况下应显示当前安装的 Python 版本，例如：

```text
Python 3.x.x
```

继续执行：

```bash
pip --version
```

确认 Python 包管理工具可以正常使用。

### 完成要求

记录：

- Python版本
- pip版本
- 使用的开发工具
- 操作系统

## 六、任务4：简单AI学习助手欢迎程序

在任务3的基础上进一步完善程序，创建：
```text
ai_welcome.py
```

程序要求：
```text
1. 输入学生姓名；
2. 输入每天计划学习 Python 的时间；
3. 输入计划学习的天数；
4. 自动计算总学习时间；
5. 输出一段个性化学习提示。
```

例如：
```text
请输入姓名：张三
每天计划学习多少小时：2
计划学习多少天：14

张三，你计划进行14天Python学习。
预计总学习时间：28小时。
欢迎开启你的AI编程学习之旅！
```

提示

可以使用：
```python
name = input("请输入姓名：")
hours = float(input("每天计划学习多少小时："))
days = int(input("计划学习多少天："))

total = hours * days
```

## 七、任务5：认识课程GitHub仓库

打开课程仓库：
```text

```

```text

```

了解各目录的用途：

目录	用途
examples	课堂示例代码
labs	日常实训任务


## 八、任务6：Git基本操作体验

如果计算机已经安装 Git，在终端执行：

```bash
git --version
```

查看 Git 版本。

复制课程仓库的 HTTPS 地址，并尝试使用：

```bash
git clone 仓库地址
```

将课程仓库下载到本地。

进入仓库目录后，可以执行：

```bash
git status
```

查看当前仓库状态。
