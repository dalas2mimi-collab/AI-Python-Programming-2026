# Python 程序设计实训

> 人工智能专业《高级语言程序设计实训》课程实验导航

本实训课程以 **Python 程序设计基础** 为核心，面向人工智能专业学生，通过由浅入深的实验任务，逐步培养程序设计、数据处理、模块化开发和人工智能应用实践能力。

课程实验不完全按照教材章节机械划分，而是采用 **“基础知识点训练 → 综合程序设计 → 数据分析 → AI应用”** 的渐进式组织方式。前期通过多个小型实验强化基本语法和程序设计能力，后期通过跨章节综合任务，将函数、文件、面向对象、NumPy、Pandas 和机器学习等知识逐步串联起来。

---

## 一、实训学习路线

本课程共设置 **16 个 Lab**，整体分为四个阶段：

### 第一阶段：Python 编程基础

**Lab 01 ～ Lab 06**

完成开发环境配置，掌握变量、数据类型、运算符、条件判断和循环结构，能够独立编写简单的 Python 程序。

```text
开发环境
   ↓
输入与输出
   ↓
变量和表达式
   ↓
条件判断
   ↓
循环结构
   ↓
简单程序设计
```

### 第二阶段：程序设计与数据组织

**Lab 07 ～ Lab 12**

掌握 Python 常用数据结构、函数、文件操作、异常处理和面向对象程序设计方法，逐渐从单个知识点练习过渡到完整程序开发。

```text
字符串与列表
      ↓
字典与集合
      ↓
数据结构综合
      ↓
函数与模块化
      ↓
文件与数据处理
      ↓
面向对象程序设计
```

### 第三阶段：数据处理与人工智能基础

**Lab 13 ～ Lab 15**

结合人工智能专业特点，学习 NumPy、Pandas、Matplotlib 和 Scikit-learn，完成从数据读取、处理、分析到机器学习模型训练与评价的基本流程。

```text
NumPy
   ↓
Pandas
   ↓
数据分析与可视化
   ↓
机器学习
```

### 第四阶段：AI 综合应用

**Lab 16**

综合运用前面所学知识，完成一个小型人工智能应用，为后续课程综合项目做好准备。

```text
Python基础
    +
数据结构
    +
函数与文件
    +
NumPy / Pandas
    +
机器学习
        ↓
AI Mini Application
```

## 三、各阶段学习目标

### 阶段一：从“能运行”到“会编程”

完成 Lab 01～06 后，应能够：

* 配置并使用 Python 开发环境；
* 独立创建、运行和调试简单 Python 程序；
* 正确使用变量、基本数据类型和表达式；
* 使用条件结构解决分支问题；
* 使用循环结构解决重复计算问题；
* 将实际问题转化为简单的程序处理流程。

---

### 阶段二：从“写代码”到“设计程序”

完成 Lab 07～12 后，应能够：

* 使用字符串、列表、元组、字典和集合组织数据；
* 根据实际问题选择合适的数据结构；
* 使用函数对程序进行分解和模块化；
* 进行文本文件和结构化数据的基本读写；
* 使用异常处理提高程序的健壮性；
* 理解类和对象的基本思想；
* 完成具有一定规模的 Python 综合程序。

---

### 阶段三：从“程序设计”到“数据与AI”

完成 Lab 13～15 后，应能够：

* 使用 NumPy 进行数组和数值数据处理；
* 使用 Pandas 读取、整理和分析数据；
* 使用 Matplotlib 对数据进行基本可视化；
* 理解人工智能任务中的基本数据处理流程；
* 使用 Scikit-learn 完成基础机器学习模型的训练和预测；
* 对模型结果进行基本评价。

---

### 阶段四：从“实验任务”到“AI应用”

完成 Lab 16 后，应能够将前面学习的知识组合起来，形成基本的人工智能程序开发流程：

```text
问题分析
   ↓
数据读取
   ↓
数据处理
   ↓
程序功能设计
   ↓
模型训练
   ↓
结果评价
   ↓
结果展示
```

完成 Lab 16 后，将进一步进入课程的 **综合项目（Projects）** 阶段。

## 四、实验任务的基本形式

不同阶段的实验任务规模不同。

### 前期实验

Lab 01～08 以短小、明确的编程任务为主，一个 Lab 中通常包含多个小任务，例如：

* 编写简单计算程序；
* 完成条件判断；
* 完成循环统计；
* 处理字符串和列表；
* 使用字典组织数据。

重点是通过充分练习掌握 Python 基础。

### 中期实验

Lab 09～12 开始采用综合任务，一个实验可能同时使用多个章节的知识。

例如：

```text
数据结构
   +
循环
   +
函数
   +
文件
   +
异常处理
        ↓
完整的数据管理程序
```

重点由“学习某个语法”逐渐转变为“利用 Python 解决问题”。

### 后期实验

Lab 13～16 以数据处理和人工智能应用为背景，通过较完整的任务训练学生完成：

```text
数据 → 分析 → 程序 → 模型 → 结果
```

重点培养面向人工智能应用的 Python 编程能力。

## 五、Lab目录说明

不同 Lab 根据任务复杂程度采用不同的目录结构。

简单实验可能只有：

```text
labXX-name/
└── README.md
```

综合实验可能包含：

```text
labXX-name/
│
├── README.md
├── starter/
├── data/
└── assets/
```

其中：

| 内容          | 作用          |
| ----------- | ----------- |
| `README.md` | 实训任务书、要求和提示 |
| `starter/`  | 实训起始代码      |
| `data/`     | 实训所需数据      |
| `assets/`   | 图片及其他辅助资源   |

并不是每个 Lab 都必须包含所有目录。

## 六、实验完成建议

完成每个 Lab 时，建议按照以下流程进行：

1. 阅读 Lab 中的 `README.md`；
2. 明确本次实训目标和任务；
3. 独立创建或完善 Python 程序；
4. 运行并检查程序结果；
5. 对程序进行必要的修改和调试；
6. 完成拓展任务或思考题；
7. 整理本次实验代码和实验记录。

建议优先独立分析和编写程序，在遇到问题时，再通过教材、课程资料、官方文档或其他辅助工具查找解决方法。

## 八、实训要求

在整个实训过程中，应逐步形成以下基本习惯：

* 保持程序代码格式规范；
* 为变量和函数使用具有明确含义的名称；
* 避免无意义地复制代码；
* 对较复杂程序进行适当的模块划分；
* 及时运行和测试程序；
* 对程序错误进行分析和调试；
* 保留必要的实验代码和运行结果；
* 逐步养成使用 Git 和 GitHub 管理代码的习惯。
