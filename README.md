# AI-Python-Programming-2026

## 人工智能专业 高级语言程序设计实训课程

本课程面向人工智能专业本科生，
以 Python 程序设计基础为核心，
结合人工智能应用场景，
培养学生程序设计能力、数据处理能力和工程实践能力。
本仓库用于管理《高级语言程序设计实训》课程实验代码、
示例程序以及综合项目开发。

---

## Course Objectives

通过本课程学习，学生能够：

1. 掌握 Python 基础语法和程序设计方法；
2. 掌握数据结构、函数、文件和面向对象程序设计；
3. 熟悉 Python 第三方库使用方法；
4. 了解 Python 在人工智能领域中的应用；
5. 掌握 Git 版本管理和软件项目开发流程。
